# Критерії оцінювання результатів навчання учнів з фізики

Готовий односторінковий вебзастосунок для публікації на **GitHub Pages**.

## Можливості

1. Вибір одного з 5 показників:
   - За когнітивними процесами
   - За навчальною діяльністю
   - За рівнем самостійності
   - За рівнем комунікації та взаємодії
   - За частотою вияву вмінь
2. Вибір одного з 12 дескрипторів для показника.
3. Текст дескрипторів у списку взято дослівно з наданого документа.
4. Автоматичне визначення бала 1–12.
5. Формування картки учня з прізвищем, ім'ям, показниками, обраними дескрипторами та балами.
6. Розрахунок середньої оцінки за доданими показниками.
7. Завантаження картки у PNG.
8. Друк або збереження картки у PDF.
9. Адаптивна верстка для ноутбука, планшета та смартфона.
10. Не потрібен сервер або база даних.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub.
2. Завантажте `index.html`.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Вкажіть гілку `main` і папку `/ (root)`.
6. Збережіть налаштування.
7. Через деякий час GitHub Pages опублікує сайт.

## Важливо

Застосунок використовує бібліотеку `html2canvas` через CDN для формування PNG. Для роботи PNG-перетворення потрібне підключення до Інтернету. Сам вибір критеріїв та формування картки працюють у браузері.

Весь текст дескрипторів у програмі сформовано без зміни формулювань із наданого DOCX.


## Структура репозиторію

У корені репозиторію має бути саме:

- `index.html` — головна сторінка програми
- `README.md` — інструкція
- `.nojekyll` — службовий файл для GitHub Pages

**Не потрібно завантажувати Python-код.** Браузер має відкривати саме файл `index.html`.
